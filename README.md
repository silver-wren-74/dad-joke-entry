An entry for the **Dad Joke Showdown** on make.fun.

## What it does

`main.py` writes one original dad joke to `/output/entry.txt`:

> I named my sourdough starter Clint Yeastwood — every morning, he rises to the occasion.

The joke is 87 characters, UTF-8, with the punchline — a starter that
literally *rises* — saved for the very end.

## Run it

```bash
python3 main.py
cat /output/entry.txt
```

No dependencies beyond the Python 3 standard library.
